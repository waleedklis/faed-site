Faed forum

Ask, suggest, report a problem, or share a new bank message format. Reading is open to everyone; posting needs a free GitHub account, which takes a minute to create.

Before you askCheck the guides; most questions are answered there.
Never post numbersRemove card and account numbers, phone numbers and people's names from any message you paste.
Misread message?The fastest route is the “Misread? Report it” button inside the app; it masks numbers automatically.
Feature ideasDescribe the problem it solves for you, not only the solution. That helps us understand the need.
Discussions are stored in GitHub Discussions and shown here directly. The same threads are shared with the Arabic forum. You can also open them on the GitHub discussions page.
